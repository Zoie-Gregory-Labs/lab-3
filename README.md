# HR Management System

## Project Overview

The HR Management System is designed to help HR advisors and department managers manage employee records and produce salary reports.

The system will use Java and a MySQL database.

## Project Objectives

- Add new employee details.
- View employee information.
- Update employee records.
- Delete employee records.
- Produce salary reports for all employees.
- Produce salary reports by department.
- Produce salary reports by job role.
- Allow department managers to view salary reports for their own departments.

## Main Users

**HR Advisor**
- Manage employee records.
- Produce salary reports.
- View employee information.

**Department Manager**
- Produce salary reports for their own department.

## Technologies

- Java
- MySQL
- Maven
- Docker
- Docker Compose
- Git and GitHub
